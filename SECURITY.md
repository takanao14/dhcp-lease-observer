# Security and Privacy

This is a personal project and does not provide a security support or
response-time commitment.

## Sensitive data

Do not include credentials, private keys, host key fingerprints, internal IP or
MAC addresses, hostnames, DHCP client identifiers, profile names, inventory, or
raw router transcripts in an issue, pull request, discussion, or log excerpt.

## Parser samples

Reproduce parser problems with a minimal anonymized fixture. Use documentation
address space such as `192.0.2.0/24` and synthetic locally administered MAC
addresses such as `02:00:00:00:00:01`. Replace site-specific host, interface,
profile, and client names while preserving only the syntax needed to reproduce
the problem.
